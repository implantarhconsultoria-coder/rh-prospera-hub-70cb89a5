# Fora do escopo desta entrega

- App dos Mecânicos.
- WhatsApp API, Evolution API ou Meta Cloud API.
- SMS.
- OTP por mensageria.
- Alteração de ponto, abastecimento, frota ou demais módulos operacionais.
- Geração automática de holerite fora do fluxo já existente.

A entrega é exclusivamente um acréscimo ao fluxo de Pagamento/Holerite da Plataforma TOPAC Web.
