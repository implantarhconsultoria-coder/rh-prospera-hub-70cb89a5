# Pacote operacional

Este pacote consolida a operação aprovada em 16/09/2026. O Almoxarifado V4 implementa a simplificação imediata do fluxo no front-end usando as estruturas existentes. As mudanças persistentes de banco para histórico de PDFs assinados, autorização de hora extra e arquivamento automático da frota devem ser aplicadas quando o acesso de escrita ao projeto Supabase estiver disponível para execução.
