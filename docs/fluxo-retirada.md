# Fluxo único de retirada

Funcionário → materiais/quantidades → observação estruturada ou janela inteligente → confirmar. A confirmação chama a rotina de carga/retirada existente e baixa o estoque no mesmo ato. Não existem botões operacionais separados para saída genérica, carga do funcionário ou carga do carro nesta versão.
